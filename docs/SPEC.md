- 煞車在緊急時讓葉輪停止。
- （LBL 輔助）偏航驅動讓葉輪保持對風；傳動系統把低速轉動轉換成高速轉動給發電機。

## 2. 座標慣例

| 項目 | 定義 |
|---|---|
| 單位 | 1 單位 = 1 公尺（示意比例） |
| 座標系 | 右手座標系，**+Y 朝上** |
| 世界原點 | 塔架中心軸與地面（y = 0）交點 |
| 葉輪正面 | 偏航角 ψ = 0° 時，葉輪正面（上風面）朝世界 **+Z** |
| 方位 | **+Z = 北**、−X = 東、−Z = 南、+X = 西（從上往下看、北朝上時東在右邊） |
| 風向角 θ（氣象慣例） | 風**吹來**的方位角，從北方起算，從上往下看**順時針為正**：0° 北風、90° 東風、180° 南風、270° 西風。上風方向 u(θ) = (−sin θ, 0, cos θ) |
| 偏航角 ψ | 偏航節點繞 +Y 的右手旋轉角（從上往下看逆時針），葉輪面朝 (sin ψ, 0, cos ψ) |
| 對風 | 機艙正對風時 ψ = −θ（`yawForWind`） |
| 葉輪轉向 | 從上風處看**順時針** ⇒ 繞葉輪軸（指向上風）的角速度為負（`rotorSpinSign = −1`） |
| 槳距角 β | 0° = 工作位置；增加時前緣轉向上風；90° = 順槳（弦線與風平行）。繞葉片局部 +Y 的旋轉 = `pitchSign × β`，`pitchSign = −1` |

## 5. 傳動系統（第二階段已建模；齒輪嚙合在第三階段）

沿傳動中心線（drivetrain z，往葉輪為正）：輪轂法蘭 3.7 → 主軸 3.6～0.6（兩個主軸承 2.9、1.3）→ 齒輪箱 0.6～−1.9 → 高速軸 −1.9～−3.4（煞車 −2.3、聯軸器 −2.9）→ 發電機 −3.5～−6.0。

### 齒輪箱：真實構造 vs. 教學示意

| | 真實 2 MW 級（一般常見） | 本模型 |
|---|---|---|
| 級數 | 1 級行星 + 2 級平行軸（常見配置之一） | 相同級數 |
| 總速比 | 約 1:80～1:120 量級 | **1:112**（5 × 4 × 5.6，教學示意） |
| 齒數、模數 | 依工程設計 | 示意值：行星 24/36/96（模數 0.02 m）、平行軸 80→20、84→15 |
| 精度 | 齒形、修形、軸承、潤滑等細節 | **不具工程精度**，只保留「大帶小加速」與轉向關係 |

第二階段的齒輪箱只做外殼（行星段圓筒 + 平行軸段箱體），第三階段才打開看齒輪。

### 轉動關係（第二階段動畫）

| 節點 | 轉法 |
|---|---|
| `lowSpeedShaft`（主軸） | 與葉輪剛性連接，角度永遠等於葉輪 |
| `highSpeedShaft`（高速軸、聯軸器、煞車盤、發電機轉子） | 與葉輪**同向**（行星級同向 × 兩級平行軸各反向一次）。實際轉速是主軸的 112 倍，畫面上限每秒 1.2 圈，**教學示意** |
| 煞車鉗、發電機定子、齒輪箱外殼、主軸承 | 固定在傳動框架上，不轉 |

### 其他內部系統

- **槳距系統**：每片葉片根部一組變槳軸承（環）+ 變槳馬達，裝在輪轂內，掛在 `blade*` 節點（不隨槳距轉）。
- **偏航系統**：塔頂內齒環（固定在塔架）+ 4 組偏航馬達（裝在機座上、隨機艙轉），馬達小齒輪咬住內齒環。
- **控制器**：機艙後方的控制櫃（示意）。

## 5b. 電力路徑（教學示意）

`CABLE_ROUTE` 定義每一段，測試檢查首尾相接：

發電機下方 → 機座上方 → 偏航中心往下（機艙轉向時電纜不會斷開）→ 塔架中心往下 → 塔底 → **地下電纜**（地面上的咖啡色路徑 + 橘色虛線表示埋在地下）→ 變壓器 → 地下電纜 → 第一根電桿 → 沿電桿往上接到橫擔 → 架空電線。

真實風場的電纜多半看不到，畫面上的路徑是為了讓兒童看出「有接起來」。有些機型的變壓器裝在機艙或塔底，本模型採塔架旁的箱型變壓器。

## 5d. 齒輪箱連動（第三階段）

齒輪組由 `gearLayout()` 從配置資料計算位置，`gearTrainAngles(θc)` 由主軸（行星架）角度算出每個齒輪的角度：

| 節點 | 角度（相對傳動框架 +Z） | 從前方看 |
|---|---|---|
| 行星架 = 主軸 | θc | 順時針 ×1 |
| 太陽齒輪軸（太陽齒輪 + 第一級大齒輪） | 5·θc | 順時針 ×5 |
| 行星齒輪（自轉，絕對角） | (1 − 96/36)·θc + φk | 逆時針，同時隨行星架公轉 |
| 中間軸（第一級小齒輪 + 第二級大齒輪） | −20·θc + φ | 逆時針 ×20 |
| 高速軸（第二級小齒輪） | 112·θc + φ | 順時針 ×112 |

- **嚙合相位**：每個齒輪模型的第 0 齒朝局部 +X；φ 讓每一對齒輪在接觸線上永遠是「齒對齒溝」。測試在多個角度檢查太陽–行星、行星–環、兩級平行軸共 8 個嚙合點。
- **教學簡化**：齒形是梯形，不是漸開線；行星架做成三支手臂（真實的是兩片夾板），才看得到後面的行星齒輪。
- **轉速**：拆解模式下所有齒輪依真實速比連動；為了讓高速軸每秒只轉約 1.2 圈，葉輪放慢到約 0.64 rpm（教學示意）。其他模式維持展示轉速，高速軸另外放慢。

## 5e. 機械拆解（第三階段）

`EXPLODE.offsets` 定義每個零件拆開時的位移（齒輪箱外殼往上 3.2 m、主軸往前 2.4 m、發電機轉子從定子滑出等），整個葉輪往前 4.5 m。在會轉動的節點底下的零件只能沿軸向移動（測試檢查）。拆開／合起來只改位置，約 1.2 秒。

拆解模式可以：拆開或合起來、「只看這個」、把零件「藏起來」、「全部顯示」還原；「看齒輪」會暫時藏起齒輪箱外殼、主軸、主軸承和偏航系統，從前方斜上看齒輪組。

## 5f. 輸電路徑（場景）

風機 → 地下電纜 → 箱型變壓器 → 地下電纜 → 配電電桿（三相三條線）→ **變電所**（圍籬、進線／出線門型架、主變壓器、控制室）→ **高壓輸電鐵塔**一路延伸到遠方（送往城市）。樹與山丘不會擋在線路走廊上（測試檢查）。全部為示意比例。

## 6. 發電實驗的模擬（第四階段；2026-10-23 物理檢查後改為轉動動力學，`src/sim/turbineSim.js`）

### 物理（可測試）

| 量 | 公式 | 說明 |
|---|---|---|
| 風的功率 | P_wind = ½ ρ A v³ | ρ = 1.225 kg/m³、A = π·45² ≈ 6362 m² |
| 葉輪接住 | P_aero = P_wind · Cp(λ, β) | λ = ωR/v（葉尖速比）、β 為槳距角 |
| Cp(λ, β) | 經驗公式（Heier／Slootweg 型）＋修正 | 最大約 0.44（λ ≈ 6.3、β = 0），任何情況都低於 Betz 極限 0.593 |
| 轉動 | J · dω/dt = 風的力矩 − 負載力矩 | **能量守恆**：接住的功率 − 負載功率 = 葉輪動能的變化（測試檢查，誤差 < 2%） |
| 發電機力矩 | 額定以下 kω²；額定功率後 P/ω | 轉速自動追到最佳葉尖速比；滿載時發電量剛好 2000 kW |
| 發出的電 | P = η · 發電機力矩 · ω | η = 0.94（示意） |
| 偏航誤差 γ | 有效風速 v·cos γ | 機艙還沒對準風時發電變少 |
| 尾流 | Cp = 4a(1−a)²，尾流風速 v(1−2a) | 葉輪接住越多，後面的風越慢 |

**經驗公式的修正**（公式本身只適用正常運轉範圍，以下是在範圍外補上的物理）：

| 問題 | 修正 | 理由 |
|---|---|---|
| 葉尖速比 → 0 時，大槳距下 Cp 不為 0 → 靜止時力矩無限大 | λ < 1 時 Cp 線性收斂到 0 | 功率 = 力矩 × 轉速，轉速 0 時功率必為 0 |
| 經驗公式在 λ 很小時力矩幾乎 0 → 停下的葉輪永遠轉不起來 | 加入啟動力矩 Cq0·cos β·λ·(1 − λ/3)（Cq0 = 0.01，λ < 3） | 真實葉片靜止時也有啟動力矩；順槳 90° 時為 0 |
| 負的 Cp 被截成 0 → 順槳後葉片沒有阻力，葉輪停不下來 | 允許負值（最小 −0.03，並隨轉速變慢而變小） | 順槳的葉片產生阻力，是風機減速的主要方法（氣動煞車） |
| 不發電時只有軸承摩擦 → 沒風時葉輪轉好幾分鐘 | 加入葉片空氣阻力 ≈ 3.8 × 10⁴ · ω²（N·m） | 由 3 片 × 平均弦長 2 m、阻力係數 0.01 估算；發電時已含在 Cp 裡 |

### 控制（真實風機的做法，簡化）

| 區間 | 風速 | 控制 |
|---|---|---|
| 待機 | < 3.5 m/s | 發電機不出力，葉輪靠風的力矩與摩擦、空氣阻力的平衡慢慢轉 |
| 追最佳效率 | 3.5～約 10 m/s | 槳距 0°，轉速追最佳葉尖速比，功率約與 v³ 成正比 |
| 滿載 | 約 11～25 m/s | 自動變槳（預估值＋超速修正：每超過額定 1% 多轉 1.5°），維持 16 rpm、2000 kW |
| 停機保護 | ≥ 25 m/s | 順槳到 90°；轉速降到額定 30% 前發電機繼續出力幫忙減速，之後機械煞車；風速降到 20 m/s 以下才重新啟動 |
| 手動槳距 | 任意 | 小朋友設定槳距；用「這個設定」預測會不會超過額定 15%，會就由保護系統接手（不會一開一關振盪） |
| 偏航 | — | 走最短方向對風；電纜扭超過 2 圈時改走另一邊「解纜」 |

### 隨機情境檢查（2026-10-23）

3000 組隨機情境（每組 120 秒，中途改風速、隨機切換自動／手動與槳距），共 1800 萬步：沒有 NaN、功率不超過額定、不超過 Betz 極限、能量守恆誤差最大 0.67%、最高轉速 18.30 rpm（保護值 18.4）。縮小版放在 `tests/physics.test.js`，每次都會自動執行。

### 教學示意（非精確）

- 葉輪轉動慣量 2.5 × 10⁶ kg·m²（真實約大 5～10 倍，反應更慢）。
- 風速最快每秒改變 2 m/s（拉滑桿時，風要幾秒才變大／變小；陣風本來就需要時間形成）。
- 偏航速度 6°/s（真實約 0.5°/s，快約 12 倍）。
- 高速軸畫面轉速上限每秒 1.2 圈；風速計畫面上限每秒 2 圈。
- 黃色能量點不是電的真實樣子或速度。

## 6b. 兒童學習功能與語音朗讀（第五階段）

### 語音朗讀（`src/learning/speech.js`）

- 只用瀏覽器內建的語音合成（Web Speech API），**不使用外部語音服務**。
- 語音選擇：台灣華語（zh-TW）優先 → 其他華語 → 都沒有就**隱藏朗讀按鈕**（不顯示錯誤）。粵語（zh-HK）讀法不同，不採用。語音清單是非同步載入的，載入後才顯示按鈕。
- 速度 0.9、音高 1.05（適合兒童）。換零件或關閉介紹卡時停止朗讀。
- 讀音修正（只影響朗讀，畫面文字不變）：

| 畫面文字 | 朗讀用文字 | 原因 |
|---|---|---|
| 槳距、順槳、槳 | 獎句、順獎、獎 | 「槳」較少見，部分語音會唸錯 |
| 偏航 | 篇杭 | 確保唸 piān háng |
| 輪轂 | 輪鼓 | 「轂」罕用字 |
| 解纜、電纜 | 解覽、電覽 | 確保唸 lǎn |
| kW、m/s、rpm | 千瓦、公尺每秒、轉每分鐘 | 單位要唸成中文 |
| 59% | 百分之59 | 百分比 |

朗讀按鈕出現在：零件介紹卡、每個小任務、考考你的題目、導覽每一步。

### 學習功能

| 功能 | 內容 | 規則 |
|---|---|---|
| 小任務（`missions.js`） | 8 個：找到發電機、齒輪箱、太陽齒輪；讓風機發電、滿載、轉向東風、停機保護、自己把葉片轉開 | 自動判斷完成並提示；不強制完成 |
| 考考你（`quiz.js`） | 8 題點選題，每題 3 個選項 | 答完立刻說明原因；可跳過、隨時結束 |
| 操作說明（`tour.js`） | 5 步：轉動縮放、點零件、四種玩法、工具與任務、自動導覽 | 第一次打開才顯示；可跳過；之後從「學習」→「操作說明」再看（和「自動導覽」不同） |

| 自動導覽（`guide.js`） | 17 段、4 章：風為什麼能推動葉片 → 機艙裡的發電過程 → 電怎麼送到家裡 → 風大風小怎麼辦 | 標題旁的按鈕啟動／停止；字幕＋語音；畫面（模式、外殼、風速風向、相機、標示零件）自動切換 |

### 自動導覽的規則

- 播放狀態放在集中 store：`guideStep`（第幾段，null = 沒有播放）、`guidePaused`。
- **換段時機**：有中文語音時，最後一句唸完再停 1.2 秒；沒有語音時依字數估計（每字 0.26 秒）。每段至少停留 `minSec`，讓畫面上的變化來得及發生（例如停機、機艙轉向）。語音唸完的通知有時不會來，最多等估計時間的 1.8 倍再換段，不會卡住。
- 朗讀時依句號切成短句排隊唸，避免部分瀏覽器唸太長的一句會中斷。
- **暫停**：停止朗讀與計時；**繼續**：這一段從頭再唸（手機瀏覽器的語音暫停不可靠）。另有上一段、下一段、停止。
- **小朋友自己操作就停止**：拖曳／縮放／點畫面，或自己換模式、點零件、開面板、調風速風向槳距。導覽自己改狀態時不算。
- 導覽時收起發電實驗面板、介紹卡等，3D 畫面中心移到標題列與字幕卡之間；也不替小朋友完成小任務。
- **特別的畫面**：
  - 葉片：葉輪暫停，一片葉片轉到水平，鏡頭靠近；另外顯示「葉片切開來看」小圖，翼型用 3D 模型同一個斷面公式（60% 半徑處，扣掉扭轉）畫出，箭頭是教學示意。
  - 跟著電走：塔架暫時變透明（`towerXray`），鏡頭沿送電路徑從發電機往下走到變壓器；鏡頭在「塔架 → 變壓器」連線的下風側，不會被塔架或葉片擋住。
  - 地面零件（變壓器等）：從塔架的另一邊看過去。
  - 風小、風大：先快轉模擬（字幕卡標示「快轉了幾秒」），字幕卡顯示風速、葉輪轉速、發電機轉速、發電量長條；發電機發亮程度表示發電量（教學示意）。
- 高速軸畫面轉速改為**依固定比例放慢**（葉輪額定轉速時每秒 1.2 圈），風小時看得出比較慢；原本是固定上限，風小風大看起來一樣快。
- 文字裡的數字（切入／額定／切出風速、額定功率、齒輪速比、葉片長度）由規格產生；測試用真正的模擬確認導覽說的現象（8 m/s 約每分鐘 10 圈、葉尖比汽車快、風太小快轉後只空轉不發電、風大快轉後滿載且轉速是風小時的兩倍以上、27 m/s 在該段時間內停機順槳、風向轉 90° 在該段時間內轉到位）。

- 學習資料依難度分層（`elementary` 已填、`junior` 第六階段）。
- 完成的任務與「看過導覽」只存在這台裝置的瀏覽器（localStorage）；無法儲存時（例如私密模式）照常使用，只是不記得進度。

### 可以拖曳的視窗

零件介紹卡、自動導覽字幕卡、發電實驗面板上方有「⠿ 拖我移動」把手，按住就能移動（`src/ui/draggable.js`）：

- 位置是相對原本位置的位移，存在 store 的 `panelPos`，手機版和桌面版分開記；也存在這台裝置的瀏覽器（localStorage），重新整理後還在。
- 移動後出現「歸位」按鈕；拖回原位附近也算歸位。視窗不會被拖出畫面，轉向或視窗大小改變時會自動拉回畫面內。
- 移動過的字幕卡或實驗面板，3D 畫面就不再為它讓出位置（照使用者放的位置）。
