# 風力發電機規格文件（第一階段）

> **示意性質**：本網站的風機是「具代表性的 2 MW 級、陸域、三葉片、上風式、水平軸、具齒輪箱」風力發電機的**示意比例**模型，不對應任何廠牌或型號，也不具工程精度。
> 所有數值的唯一來源是 [`src/spec/turbineSpec.js`](../src/spec/turbineSpec.js)，本文件只做說明。

從搜尋摘要得到、並用於零件配置的內容：

- 零件項目：風速計（anemometer）、葉片、煞車、控制器、齒輪箱、發電機、高速軸、低速軸、機艙、槳距系統、葉輪、塔架、風向標、偏航驅動與偏航馬達。
- 機艙內包含齒輪箱、低速軸與高速軸、發電機與煞車。
- 葉輪直接或經由軸與一系列齒輪連接發電機；齒輪讓發電機可以做得較小。
- 偏航驅動讓**上風式**風機在風向改變時轉向對風，由偏航馬達提供動力；下風式風機不需要偏航驅動。
- 風向標量測風向並提供給偏航驅動；風速計把風速資料送給控制器。
- 槳距系統調整葉片對風的角度，藉此控制葉輪轉速，並在風太大或太小時保護葉輪。
- 煞車在緊急時讓葉輪停止。
- （LBL 輔助）偏航驅動讓葉輪保持對風；傳動系統把低速轉動轉換成高速轉動給發電機。

**未經 DOE 原文核對的數值**：轉速、速比、切入／額定／切出風速、偏航速度、各部尺寸等，是依一般公開知識設定的**代表性教學值**，在下方標為「示意」。若之後環境可以連線 energy.gov，應再核對原文並更新本節。

## 2. 座標慣例

| 項目 | 定義 |
|---|---|
| 單位 | 1 單位 = 1 公尺（示意比例） |
| 座標系 | 右手座標系，**+Y 朝上** |
| 世界原點 | 塔架中心軸與地面（y = 0）交點 |
| 葉輪正面 | 偏航角 ψ = 0° 時，葉輪正面（上風面）朝世界 **+Z** |
| 風向角 θ | 風**吹來**的方向；θ = 0° 表示風從 +Z 吹來、往 −Z 吹；從上往下看**逆時針為正**（繞 +Y 右手方向）。上風方向 u(θ) = (sin θ, 0, cos θ) |
| 對風 | 機艙正對風時 ψ = θ |
| 葉輪轉向 | 從上風處看**順時針** ⇒ 繞葉輪軸（指向上風）的角速度為負（`rotorSpinSign = −1`） |
| 槳距角 β | 0° = 工作位置；增加時前緣轉向上風；90° = 順槳（弦線與風平行）。繞葉片局部 +Y 的旋轉 = `pitchSign × β`，`pitchSign = −1` |

## 3. 父子群組（場景圖）

```
world
├─ foundation          基礎
├─ tower               塔架（原點在地面）
└─ yaw                 位置 (0, 78, 0)＝偏航軸承頂面；繞 +Y 轉偏航角 ψ
   └─ nacelle          機艙局部座標原點＝偏航軸承頂面中心
      └─ drivetrain    位置 (0, 2.0, 0)；繞 X 轉 −5°（傳動軸傾角，葉輪端抬高）
         └─ rotor      位置 (0, 0, 5.0)；繞局部 +Z（葉輪軸，指向上風）旋轉
            └─ blade0..2   繞 Z 分配 0°/120°/240°，再繞局部 X 轉錐角 2.5°（葉尖往上風）
               └─ pitch0..2  位置 (0, 1.6, 0)＝變槳軸承；繞葉片局部 +Y 轉槳距角
```

- **世界座標**：只有 foundation、tower、yaw、場地物件直接使用。
- **局部座標**：機艙內所有零件使用機艙局部座標；傳動系統零件使用 drivetrain 座標（z 軸＝傳動中心線，正值往葉輪）。
- 父子關係的完整圖見 [connections.md](connections.md)。

## 5. 傳動系統（第二、三階段建模，位置已定義）

沿傳動中心線（drivetrain z，往葉輪為正）：輪轂法蘭 3.7 → 主軸 3.6～0.6（兩個主軸承 2.9、1.3）→ 齒輪箱 0.6～−1.9 → 高速軸 −1.9～−3.4（煞車 −2.3、聯軸器 −2.9）→ 發電機 −3.5～−6.0。

### 齒輪箱：真實構造 vs. 教學示意

| | 真實 2 MW 級（一般常見） | 本模型 |
|---|---|---|
| 級數 | 1 級行星 + 2 級平行軸（常見配置之一） | 相同級數 |
| 總速比 | 約 1:80～1:120 量級 | **1:112**（5 × 4 × 5.6，教學示意） |
| 齒數、模數 | 依工程設計 | 示意值：行星 24/36/96（模數 0.02 m）、平行軸 80→20、84→15 |
| 精度 | 齒形、修形、軸承、潤滑等細節 | **不具工程精度**，只保留「大帶小加速」與轉向關係 |

齒輪組以「配置資料」描述（`GEARBOX_CONFIGS`），可新增其他配置；測試會檢查行星齒數關係（環 = 太陽 + 2 × 行星）、中心距 = 模數 ×（齒數和）/ 2，以及「額定葉輪轉速 × 速比 ≈ 發電機轉速」。
